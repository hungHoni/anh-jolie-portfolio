# Anh Jolie — Retoucher & Graphic Designer Portfolio

Interactive tactile desk portfolio for **Anh Jolie** (*Retoucher & Graphic Designer* in Ho Chi Minh City, Vietnam), inspired by `jackiehu.design` and customized with Anh Jolie's Behance lookbooks, beauty retouching campaigns, and curated moodboards.

## Highlights

- **Interactive Hero Desk Stage (Desktop & Mobile):**
  - 3 desktop layout modes (*Coffee / Messy Desk*, *Cleaned-Up Mode*, *Notebook Mode*) + custom mobile collage layout (`<= 809px`).
  - Tactile Polaroid portrait of Anh Jolie with Fujifilm X-T4, spinning vinyl music player (*Souleance — Jazz et thé vert*), interactive AirDrop card, macOS folder, and 13 real sound effects.
- **In-Page Editorial Lookbook & Studio Popup Modal:**
  - Clicking any project in `Recently Made ▶` or any curation in `Moodboards & Curations ⁕` opens an in-page macOS Studio + Editorial Lookbook modal with warm ambient backdrop lighting, a framed gallery print viewer, `✨ Compare Raw / Retouched` grading toggle, a numbered Contact Sheet (`RAW_01.CR3`), dotted notebook story notes, and a seamless `Up Next →` switcher.
- **Editorial Artist Profile (`About ⌘`):**
  - Features Anh Jolie's taped Polaroid portrait, live availability status, specialty tags, and quick archive triggers.
